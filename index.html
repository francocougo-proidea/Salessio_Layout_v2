Saléssio

1° Passo - Como ativar o Layout?

Vá em Catálogo -> Parâmetros Sistema.

Procure por LAYOUT -> Mude o valor para 1 -> Clique em 💾 para salvar

Após salvar, é necessário sair do Saléssio e entrar novamente para visualizar a mudança.

2° Passo - O que mudou?

Todas mudanças foram feitas com o objetivo de deixar o sistema mais funcional, responsivo, e intuitivo para os usuários.

Inicio - ANTIGO

Inicio - NOVO

O menu superior foi realocado na lateral para melhor visibilidade do Banner (12) e Notícias (13).

Os botões que são exclusivos de administradores (Cadastro, Catálogo, Dashboard) foram agrupados dentro do botão Abrir Gestor (8).

Além disso, é possível ocultar esse Menu  Lateral clicando no botão ≡.

Escolher Produto - ANTIGO

Escolher Produto - NOVO

A Barra de Pesquisa (3) foi para o canto superior da página, facilitando sua visualização.

Agora é possível ocultas os Filtros Iniciais (1) (2).

O Carrinho (4) só vai ficar visível caso você já esteja com algum carrinho aberto.

Configurar Produto - ANTIGO

Configurar Produto - NOVO

A Tela de Configurações e o Painel de Visualização foram invertidos, para que a primeira coisa que o usuário veja seja a aba de configurar o produto.

No momento em que o usuário preencher todas Características o produto será desenhado automaticamente.

O botão de Salvar (6) agora leva automaticamente para a tela de orçamento.

A tela que aparece ao clicar em uma característica foi melhorada.

Como agora é possível ocultar o menu de opções, o Painel de Visualização fica bem maior.

Orçamento - ANTIGO

Orçamento - NOVO

Para acessar as informações de Dados de Orçamento (1), Dados do Cliente (2), Dados Complementares (3) e Opções de Pagamento (4) é necessário selecioná-las primeiro.

Os Dados de Orçamento (1) e os Dados do Cliente (2) foram agrupados em uma única tela: Orçamento.

É possível expandir, ou ocultar as informações dos Produtos (5), otimizando o espaço na tela.


Os Botões Adicionais (8) foram separados :

    - Exclusão Múltipla e Adicionar Item agora ficam no canto inferior direito.

    - Os demais estão separados em 4 grupos no canto superior direito:
    Impressões do Orçamento; Downloads de Orçamento; Logs de Orçamento; Ações do      Orçamento.

Outras telas também tiveram seu layout otimizado, contudo as que foram mostradas acima são as mais importantes.

Além do Layout, há outras mudanças que foram implementadas nessa nova atualização.
Vamos falar sobre elas a seguir.

3° Passo - Habilitar Visualização de Preço no Orçamento

Clique em Abrir Gestor

Vá em Catálogo -> Parâmetros Sistema.

Procure HABILITA_PRECO_NO_CONFIGURADOR -> Mude o valor para 1 -> Clique em 💾 para salvar

Recarregue a página para aplicar a mudança.
Agora é possível ver o preço do produto durante sua configuração.

4° Passo - Obrigar preenchimento de informações específicas

Clique em Abrir Gestor

Vá em Catálogo -> Parâmetros Sistema.

-> Procure OBRIGA_CAMPOS_AO_CRIAR_ORCAMENTO

-> Digite quais campos deseja marcar como obrigatórios    
    - DES : Descrição
    - OC : Ordem de Compra
    - AMB : Ambiente
    - OBS : Observação
    - Use # para separar os códigos, igual no exemplo abaixo.

-> Clique em 💾 para salvar

Recarregue a página para aplicar a mudança.
Agora, ao salvar seu produto, irá aparecer uma tela exigindo que você preencha essas informações antes de prosseguir.
